# 顶部横向学习导航设计

## 目标

把「学习概览」和「学习资料」从左侧侧边栏移动到顶部横向导航中，参考 `../visual-worktree` 的主视图切换方式，让主内容区获得完整横向空间。

## 方案

采用顶部 `Header` 内的 `Segmented` 控件作为主导航。左侧显示产品名「学习追踪」和两个入口：「学习概览」「学习资料」。右侧继续保留日期、主题切换按钮和设置抽屉入口。

`App.tsx` 改为单列 `Layout`：顶部 `Header` + 下方 `Content`，不再渲染 `Sidebar`。根路由仍重定向到 `/dashboard`，页面路由保持不变。

## 样式

内容区仍使用紧凑工作台式留白。由于左侧栏移除，移动端不再需要针对 `.ant-layout-sider` 的固定定位规则。顶部栏高度保持 48px，内容区高度计算继续按顶部栏高度和内容区外边距/内边距处理。

## 验证

项目没有测试框架或 lint 配置，本次改动使用 `npm run build` 做 TypeScript 与 Vite 构建验证。
