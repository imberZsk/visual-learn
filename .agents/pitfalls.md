# 踩坑记录

- 用户数据位于 `~/.visualLearn`；测试必须注入临时目录，不能污染真实数据。
- Vite 开发端口动态选择，Electron 必须连接脚本实际选出的地址，不硬编码另一个端口。
- Electron 生产环境使用 `file://` 加载，资源路径必须兼容相对 base。
- Markdown、标注和总结内容均来自用户文件，解析失败要局部降级，不能导致整个资料库不可用。
- 目录扫描可能很大，禁止同步遍历阻塞主进程；刷新时防止旧请求覆盖新目录结果。
- CSS 或紧凑布局修改前检查 `scripts/check-compact-layout.mjs` 与相关回归测试。
