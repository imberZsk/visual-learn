# UI 与交互规范

## 设计基础

- 修改或新增 UI 前必须同时阅读本文件与 `style-standards.md`，二者是实现和验收约束。
- Ant Design 是唯一基础组件系统；优先使用 antd 组件、项目已有封装、主题 token 和 `@ant-design/icons`，不引入第二套组件或颜色体系。
- 产品是学习追踪与 Markdown 阅读工作台：界面应安静、紧凑、易扫描，不使用营销式大字、渐变、大阴影或无业务意义的装饰卡片。
- 信息层级优先通过间距、字号、字重、边界和语义色表达，不通过增加容器层数表达。

## 间距与层级

- 布局间距只使用 `4 / 8 / 12 / 16 / 24 / 32px`：4px 表示紧密关联，8px 表示同组元素，12px 表示关联内容，16px 表示子区块，24px 表示同级模块，32px 表示主要区域。
- 不为单个页面临时创造 6px、10px、14px、18px、20px 等布局间距。字号、行高、控件高度和固定列宽不属于布局间距，但必须集中定义。
- 表单标签到控件为 8px，控件到说明文字为 8px，同组重复项为 12px，同级字段/模块为 16px 或 24px。
- 概览指标使用单一摘要带和分隔线，不把每个数字包成装饰卡片。卡片只用于独立重复项、弹层或确需边界的工具，禁止卡片套卡片。
- 导航树、阅读区、TOC、统计带和进度项必须定义稳定尺寸或响应式网格，loading、长路径和动态文案不得使布局跳动。

## 字体、图标与导航

- 全局字体固定使用 `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；Ant Design `fontFamily` 必须使用同一字体栈，页面不得另设 `Roboto`、`Arial` 或展示字体。
- 正文和控件文字为 `14px`；资料树、表格元信息和紧凑列表为 `13px`；辅助说明为 `12px`。工作台页面标题统一 `20px`，区块标题为 `14px` 或 `16px`；Markdown 正文可按文章层级使用相对字号，但不能反向放大应用导航。
- 普通按钮和导航图标为 `14-16px`，页面标题图标不超过 `18px`；产品标识为 `28-32px`，只有统计或阅读空状态图形可以按语义适当放大。
- 顶部产品栏固定 `56px` 高，产品标识 `32px`，图标按钮使用 Ant Design 小号圆形按钮；资料树宽度保持 `264-320px`，不得为迁就长标题无限扩宽，长标题通过换行和 Tooltip 处理。
- 普通 Ant Design 按钮沿用 Visual Worktree 基线：默认高度 `32px`、小按钮 `24px`、文字 `14px`，横向内边距使用同版本 Ant Design 默认 token。禁止用全局 `min-height` 把 small 按钮重新撑大；阅读导航等特殊大触达区必须使用业务 class 明确定义。
- 字号、图标和稳定宽度必须在主题入口或相邻 CSS 集中定义，禁止用行内样式和临时组件参数单独放大。
- 内容顶栏的品牌区只显示产品名和副标题，不显示应用 Logo；应用图标只用于冷启动、Dock、安装包和系统级品牌入口，避免与紧凑导航重复占位。

## 颜色与组件

### Visual Worktree 标准色板

所有桌面项目使用 Ant Design 默认 seed `colorPrimary: #1677ff`，再分别通过 `defaultAlgorithm` / `darkAlgorithm` 派生主题；禁止按主题手写另一套 `colorPrimary`。当前锁定的关键结果如下：

| 语义                 | 亮色      | 暗色      | 使用场景                       |
| -------------------- | --------- | --------- | ------------------------------ |
| `colorPrimary`       | `#1677ff` | `#1668dc` | 主按钮、当前导航、焦点、链接   |
| `colorPrimaryHover`  | `#4096ff` | `#3c89e8` | 仅用于 hover，不能作为暗色主色 |
| `colorPrimaryActive` | `#0958d9` | `#1554ad` | 按下态                         |
| `colorPrimaryBg`     | `#e6f4ff` | `#15325b` | 低强度选中背景                 |
| `colorSuccess`       | `#52c41a` | `#49aa19` | 成功、完成                     |
| `colorWarning`       | `#faad14` | `#d89614` | 警告、需注意                   |
| `colorError`         | `#ff4d4f` | `#dc4446` | 错误、阻断、危险操作           |
| `colorBgLayout`      | `#f5f5f5` | `#000000` | 页面底层                       |
| `colorBgContainer`   | `#ffffff` | `#141414` | 侧栏和主要容器                 |
| `colorBgElevated`    | `#ffffff` | `#1f1f1f` | 卡片、弹层、浮层               |
| `colorBorder`        | `#d9d9d9` | `#424242` | 控件和主要边界                 |

- 业务组件必须消费 Ant Design token 或与上表一一映射的语义 CSS 变量，不直接写主色、状态色和主题中性色。
- 启动页无法读取 React token 时，允许静态使用上表的 `colorPrimary`；亮色为 `#1677ff`，暗色为 `#1668dc`。
- `#4096ff` 只能表示亮色 hover；不得再作为暗色默认主色、常驻图标色或 loading 色。
- 图表、代码高亮和第三方平台品牌色属于独立数据语义，必须使用专用变量，并且不能覆盖应用交互主色。

- 正文、次级文案、边界、背景和状态使用 Ant Design 主题 token 或 `src/index.css` 中 `--vl-*` 语义变量；业务页面不写明暗主题裸色值。
- 主色只用于当前导航、主要操作、链接和焦点；红色只表示错误、阻断或危险操作；绿/黄只表示完成/提醒。
- 布尔值用 Checkbox/Switch，模式用 Segmented，选项集用 Select，数字用 InputNumber，纯图标按钮必须有 `aria-label` 或 Tooltip。
- 学习完成率使用线性 Progress 便于横向比较；只有总体摘要可使用圆环 Progress。Markdown 代码高亮和用户标注属于特殊阅读语义，但色值仍在主题变量中集中定义。

## 交互与状态

- 页面专用流程留在页面或对应 hook，只有真实复用时才创建共享组件。
- 异步动作覆盖初始、loading、空、成功和失败状态；执行中防止重复提交。
- 失败提示包含失败对象和可操作原因，不能只显示“操作失败”。高频操作保持直接可达，危险操作使用确认弹层。
- 长标题、长路径和长标签必须支持换行、省略和 Tooltip/title，不得挤出主要操作。
- Electron 冷启动在 React 首次提交前使用静态主题背景、居中的 `112px` 项目图标和图标下方的 Ant Design 默认四点 `Spin` 形态；loading 容器为 `20px`、单点为 `9px`、与图标间距为 `16px`。开发态 macOS Dock 和跨平台窗口图标必须使用仓库内 `1024px` 透明项目 PNG，打包态继续使用平台安装图标；不得显示 Electron 默认图标。

## 截图验收

1. E2E 必须使用无头/隐藏 Electron 窗口，截取概览、资料空态、真实文章、设置抽屉和明暗主题。
2. 逐张检查页面层级、对齐、间距、文字截断、颜色语义、阅读宽度、操作可达性和明暗对比度。
3. 最小 Electron 窗口、长路径、长文章名下不得出现重叠、裁切、横向溢出或不可达操作。
4. 检查 hover、focus、loading、空数据、错误、完成和禁用态，不能只验收理想静态数据。
